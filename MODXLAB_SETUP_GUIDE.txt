২. Firebase Realtime Database (RTDB) সেটআপ ও ইউজার তৈরি
--------------------------------------------------------------------------------
২.১) Database Rules সেট করা:
  - Firebase Console -> আপনার প্রজেক্ট -> Realtime Database -> Rules ট্যাব।
  - প্রজেক্টের `database.rules.json` অনুযায়ী নিচের Rules বসানো থাকবে:
      * User নোট: .read = false, .write = false, .indexOn = ["user"]
      * update নোট: .read = true, .write = false
  - Publish বাটনে ক্লিক করুন।

২.২) Firebase Service Account JSON নেওয়া (শুধু Appwrite সার্ভারের জন্য):
  - Firebase Console -> Project Settings (গিয়ার আইকন) -> Service accounts।
  - "Generate new private key" ক্লিক করে JSON ফাইলটি ডাউনলোড করুন।
  - এই JSON ফাইলটি কখনোই GitHub-এ বা APK-তে রাখবেন না।

২.৩) ইউজার ও পাসওয়ার্ড তৈরি করা (Termux বা PC-তে Node.js দিয়ে):
  উপায় ক — শুধু পাসওয়ার্ডের scrypt হ্যাশ বানানো (Firebase Console-এ পেস্ট করতে):
    node scripts/migrate-passwords.js --hash "MyPass123"

  উপায় খ — কমান্ড দিয়ে সরাসরি Firebase RTDB-তে ইউজার তৈরি করা:
    FIREBASE_DB_URL="https://modx-lab-a5e41-default-rtdb.firebaseio.com" \
    FIREBASE_SERVICE_ACCOUNT_FILE="./service-account.json" \
    node scripts/migrate-passwords.js --add-user modxlab MyPass123 30

  Firebase RTDB-তে `/User/<node>`-এর ফিল্ডগুলোর নিয়ম:
    - user        : ছোট হাতের অক্ষরে ইউজারনেম (যেমন "modxlab")
    - passHash    : --hash থেকে পাওয়া "scrypt$16384$8$1$..." স্ট্রিং
                    (পুরনো plaintext "pass" ফিল্ড রাখবেন না)
    - status      : "true" (অ্যাকাউন্ট বন্ধ করতে চাইলে "false")
    - device_id   : "" (ফাঁকা রাখলে সবাই একই username/password দিয়ে যেকোনো
                    ডিভাইস থেকে লগইন করতে পারবে; এক ডিভাইসে লক চাইলে ডিভাইস আইডি দিন)
    - expire_date : "2027-12-31 23:59 +06:00" (অথবা rgtime + duration_days)

২.৪) অ্যাপ আপডেট নোটিশ (ইচ্ছামতো) — Firebase RTDB `/update/up`:
    - version : "1.0" (app/build.gradle-এর versionName-এর সাথে মিলবে)
    - message : "New update available"
    - url     : ডাউনলোড লিংক

৩. Ed25519 Keypair তৈরি (সার্ভার টোকেন সাইনিংয়ের জন্য)
--------------------------------------------------------------------------------
Termux বা PC-তে রিপোর ফোল্ডারের ভেতর থেকে নিচের কমান্ড চালান:

এটি দুটি ৬৪-অক্ষরের hex স্ট্রিং দেবে:
  1) ED25519_PRIVATE_KEY -> এটি শুধু Appwrite Function-এর Env Var-এ দেবেন (গোপন)।
  2) ED25519_PUBLIC_KEY  -> এটি শুধু GitHub Repository Secrets-এ দেবেন।

৭. Termux থেকে লাইভ SSL SPKI Pin বের করা ও `PinnedHttp.java`-তে বসানো
--------------------------------------------------------------------------------
৭.১) Termux-এ দরকারি টুল ইনস্টল করুন:
    pkg update && pkg install git openssl-tool nodejs -y

৭.২) Firebase RTDB-এর SPKI পিন বের করুন:
    openssl s_client -servername modx-lab-a5e41-default-rtdb.firebaseio.com -connect modx-lab-a5e41-default-rtdb.firebaseio.com:443 -showcerts </dev/null 2>/dev/null | awk '/BEGIN CERTIFICATE/,/END CERTIFICATE/{ if(/BEGIN CERTIFICATE/){a++}; out="fb"a".pem"; print >out }'
    for f in fb*.pem; do echo "$f:"; openssl x509 -in "$f" -pubkey -noout | openssl pkey -pubin -outform der | openssl dgst -sha256 -binary | base64; done

৭.৩) Appwrite Cloud-এর SPKI পিন বের করুন:
    openssl s_client -servername sgp.cloud.appwrite.io -connect sgp.cloud.appwrite.io:443 -showcerts </dev/null 2>/dev/null | awk '/BEGIN CERTIFICATE/,/END CERTIFICATE/{ if(/BEGIN CERTIFICATE/){a++}; out="aw"a".pem"; print >out }'
    for f in aw*.pem; do echo "$f:"; openssl x509 -in "$f" -pubkey -noout | openssl pkey -pubin -outform der | openssl dgst -sha256 -binary | base64; done

৭.৪) `app/src/main/java/com/android/support/PinnedHttp.java` এডিট করুন:
  - `FIREBASE_PINS` অ্যারেতে fb2.pem (Intermediate CA) এবং ব্যাকআপ হিসেবে
    fb1.pem বা fb3.pem-এর Base64 স্ট্রিং বসান।
  - `APPWRITE_PINS` অ্যারেতে aw2.pem (Intermediate CA) এবং ব্যাকআপ হিসেবে
    aw1.pem বা aw3.pem-এর Base64 স্ট্রিং বসান।
  - ENFORCE_PINS = true অপরিবর্তিত রাখুন।

৯. GitHub Actions থেকে Signed Release APK বিল্ড ও ডাউনলোড
--------------------------------------------------------------------------------
১. main ব্রাঞ্চে Push করার সাথে সাথে GitHub Actions -> "Build Signed Release APK"

১০. Subway Surfers গেমে Inject ও MT Manager-এ Sign করার ধাপ
--------------------------------------------------------------------------------
১০.১) ফাইল আলাদা করা:
  - `ModXLab-release-signed` থেকে পাওয়া `app-release.apk` MT Manager দিয়ে খুলুন।
  - ভেতরের `classes.dex` বের করে নাম বদলে `classes11.dex` রাখুন।
    (সতর্কতা: `classes11.dex`-এর ভেতরে কোনো smali এডিট করবেন না, তাহলে DEX hash ফেল করবে!)
  - ভেতরের `lib/arm64-v8a/libModXLab.so` নিন (সবসময় সর্বশেষ বিল্ডের নতুনটি নেবেন)।

১০.২) গেম APK-তে যোগ করা:
  - Subway Surfers (`com.kiloo.subwaysurf`)-এর APK-তে:
    1. `classes11.dex` যোগ করুন (গেমের classes*.dex-গুলোর সাথে)।
    2. `lib/arm64-v8a/libModXLab.so` যোগ করুন।
    3. গেমের নিজস্ব `classes.dex`-এ মূল Activity-র onCreate-এ কল রাখুন:
       invoke-static {p0}, Lcom/android/support/Main;->Start(Landroid/content/Context;)V
    4. গেমের `AndroidManifest.xml`-এ নিশ্চিত করুন:
       - <uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW" />
       - <uses-permission android:name="android.permission.INTERNET" />
       - <service android:name="com.android.support.Launcher"
                  android:enabled="true"
                  android:exported="false"
                  android:stopWithTask="true" />

১০.৩) MT Manager-এ নিজের Keystore ইম্পোর্ট ও Sign করা:
  - ধাপ ৬ থেকে পাওয়া `release.keystore` ফাইলটি ফোনের `/sdcard/MT2/keystore/`
    ফোল্ডারে কপি করুন।
  - MT Manager -> Auto sign -> MORE -> Manage signing keys-এ যান।
  - "Importable (MT2/keystore)" থেকে `release.keystore` সিলেক্ট করে `credentials.txt`
    থেকে KEY_ALIAS ("modxlab"), KEYSTORE_PASSWORD ও KEY_PASSWORD দিয়ে ইম্পোর্ট করুন।
  - এবার গেম APK-তে "Auto sign" করার সময়:
      * Signing Key : অবশ্যই ইম্পোর্ট করা `modxlab` সিলেক্ট করুন (Default নয়!)
      * Scheme      : `V1 + V2 + V3` সিলেক্ট করুন
      * OK চাপুন এবং ইনস্টল করুন।

১১. ভবিষ্যতে কোনো কিছু পরিবর্তন করতে হলে কোথায় কী করবেন (Cheat Sheet)
--------------------------------------------------------------------------------
১. পাসওয়ার্ড বদলানো / নতুন ইউজার / মেয়াদ বাড়ানো বা ব্লক করা:
   -> শুধু Firebase RTDB `/User` আপডেট করুন (বা `scripts/migrate-passwords.js` চালান)।
   -> অ্যাপ নতুন করে বিল্ড করার দরকার নেই।

২. "New Update Available" পপআপ বা ভার্সন বদলানো:
   -> Firebase RTDB `/update/up` ও `app/build.gradle`-এর `versionName` মিলিয়ে নিন।

৩. Mod Menu-র নতুন ফিচার, অফসেট বা UI ডিজাইন পরিবর্তন:
   -> `app/src/main/jni/Main.cpp` / `Menu.java` / `LoginHelper.java` এডিট করে
      GitHub-এ push করুন -> নতুন `classes11.dex` + `libModXLab.so` গেমে দিন।

৪. Firebase বা Appwrite ডোমেইন/প্রজেক্ট আইডি বদলাতে হলে:
   -> `app/src/main/jni/Security.cpp`-এর নিচের দিকের
      getUpdateUrl / getAppwriteEndpoint / getAppwriteProjectId / getVerifyLoginFunctionId
      ফাংশনগুলো আপডেট করুন।
   -> নতুন ডোমেইনের SPKI Pin Termux দিয়ে বের করে `PinnedHttp.java`-তে বসান।

৫. হঠাৎ লগইন করার সময় "Connection failed" দেখালে:
   -> সার্ভারের SSL সার্টিফিকেট (বিশেষ করে Leaf/Intermediate) পরিবর্তন হয়েছে কি না
      ধাপ ৭-এর `openssl` কমান্ড দিয়ে চেক করুন, নতুন পিন `PinnedHttp.java`-তে বসিয়ে
      রি-বিল্ড করুন।
